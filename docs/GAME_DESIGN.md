# LUMEN ISLE — 灯火の旅人 / Wanderer of the Last Light
ゲーム設計書 v1.0

## 1. コンセプト
> 「戦わない。急がない。ただ、島に光を還す。」

ローポリ美術 × 静かなオープンワールド探索。昼夜・天候・グライダー・灯台の上昇気流という
"移動そのものが気持ちいい" 体験を軸にした、1〜2 時間で遊びきれるコンパクトな作品。
ブラウザ (HTML5 / WebGL) で動作し、itch.io にそのままアップロードできる。

- ターゲット: 癒し系・探索系ゲーム好き (Journey / BotW / Firewatch / A Short Hike が好きな層)
- プレイ時間: クリアまで 1〜2 時間 / 100% 収集で 2〜3 時間
- 対応: デスクトップ (キーボード + マウス)、日本語 / English、ローカルセーブ

## 2. ストーリー
島を照らしていた五つの灯台が消え、色と音が眠りについた。
旅人は古びたランタンを手に草原で目を覚ます。光の欠片を集め、灯台を灯し、山頂の尖塔を目覚めさせる。
10 個の「記憶の石」が島の歴史と灯守(ともりもり)の想いを語る。

## 3. コアループ
1. 探索 — 広大な島を歩き、泳ぎ、滑空する
2. 収集 — 光の欠片 (100 個) を集める
3. 点灯 — 欠片を消費して灯台 (5 基) を灯す (必要数 6 / 10 / 14 / 18 / 22)
4. 成長 — 灯台ごとに最大スタミナ +20、ファストトラベル解禁、上昇気流の発生
5. 到達 — 全灯台点灯でオーロラが出現、尖塔が目覚める → 山頂へ → エンディング

## 4. 主要システム
| システム | 内容 |
|---|---|
| 地形 | 600m 四方の島を手続き生成。草原 / 森 / 砂漠 / 雪嶺 / 海岸 / 湖 / 岩場の 7 バイオーム |
| 移動 | 歩き・ダッシュ・ジャンプ・水泳・**滑空** (空中でSPACE再押下)。スタミナ制 |
| 上昇気流 | 点灯した灯台の光柱で滑空すると上昇できる。山頂へのルートにもなる |
| 昼夜 | 10 分で 1 日。太陽/月/星/夕焼け/オーロラ。焚き火で休むと朝・夕へスキップ |
| 天候 | 雨 (雷鳴つき)、雪嶺では降雪。霧と空色が連動 |
| 生き物 | 鹿 / うさぎ (プレイヤーに反応して逃げる) / 鳥の群れ / 蛍・花粉 |
| ロア | 記憶の石 10 個 (日英テキスト) |
| 地図 | ミニマップ + 全体マップ。点灯済み灯台へファストトラベル |
| フォトモード | P で HUD を消す、[ ] で時刻変更、C で PNG 保存 |
| セーブ | 自動 (25 秒毎 / 灯台 / ポーズ) + localStorage |
| 設定 | 言語・音量 3 系統・感度・Y 反転・画質 3 段階・フルスクリーン |
| オーディオ | すべて WebAudio による手続き生成 (BGM = ペンタトニック + パッドコード、風・雨・波・虫・鳥) |

## 5. コントロール
WASD 移動 / マウス視点 / Shift ダッシュ / Space ジャンプ・空中で滑空 / E 調べる・灯す / M 地図 / P フォトモード / C 撮影 / Esc ポーズ / ホイール カメラ距離

## 6. アート方針
- フラットシェーディング + 頂点カラーのローポリ。地形は面ごとに色ゆらぎ
- 草・木は風で揺れる (頂点シェーダ)
- HDR ブルーム (高画質時) で光の欠片・灯台・太陽が発光
- UI はガラス調の半透明パネル。ゲーム内のクエスト誘導は最小限

## 7. 技術
- three.js + React + Tailwind、Vite 単一ファイルビルド (`dist/index.html` のみで動作)
- 植生はチャンク分割した InstancedMesh (フラスタムカリング対応)
- 地形の高さはグリッドから三角形一致補間で取得 (見た目と当たり判定が一致)
