# LUMEN ISLE — 灯火の旅人

A quiet low-poly open-world exploration game (three.js + React + Vite).

- Play: https://reoreoxzkami.github.io/lumen-isle/
- Dev: `npm install && npm run dev`
- Build: `npm run build` → `dist/index.html` (single file)

Pushes to `main` deploy automatically via GitHub Actions → GitHub Pages.
